# gitops-workshop

Flux GitOps repository that deploys the Grafana observability stack to a local
Kubernetes cluster (verified on OrbStack).

## Layout

```
clusters/local/              Flux entry point for the local cluster
  flux-system/               Flux components and Git sync (generated by flux, do not edit)
  infrastructure.yaml        Flux Kustomization -> infrastructure/sources
  monitoring.yaml            Flux Kustomization -> monitoring (depends on sources)
infrastructure/sources/      HelmRepository sources
monitoring/                  HelmReleases of the Grafana stack
tests/static.sh              offline check: kustomize build + helm template of every release
tests/e2e.sh                 live check: Flux Ready, datasources healthy, logs and traces flow
```

## Stack

| Component             | Chart                                        | Role                                  |
|-----------------------|----------------------------------------------|---------------------------------------|
| kube-prometheus-stack | prometheus-community/kube-prometheus-stack   | Prometheus, Alertmanager, Grafana     |
| Loki                  | grafana-community/loki (monolithic)          | Logs, filesystem storage              |
| Tempo                 | grafana-community/tempo (single binary)      | Traces                                |
| Alloy                 | grafana/alloy                                | Pod logs to Loki, OTLP traces to Tempo |

Grafana ships with Prometheus, Loki and Tempo datasources, cross-linked
(trace IDs in logs link to Tempo, traces link back to logs).

## Bootstrap

```sh
export GITHUB_TOKEN=<token with repo admin on the repository>
flux bootstrap github \
  --owner=think-ahead-technologies \
  --repository=gitops-workshop \
  --branch=main \
  --path=clusters/local
```

## Access Grafana

```sh
kubectl -n monitoring get secret kube-prometheus-stack-grafana \
  -o jsonpath='{.data.admin-password}' | base64 -d; echo
kubectl -n monitoring port-forward svc/kube-prometheus-stack-grafana 3000:80
```

Open http://localhost:3000 and log in as `admin`.

Send traces with OTLP to `alloy.monitoring.svc:4317` (gRPC) or `:4318` (HTTP).

## Test

```sh
tests/static.sh   # before every push
tests/e2e.sh      # after Flux reconciled
```
